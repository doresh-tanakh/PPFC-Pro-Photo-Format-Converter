# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's **Report a vulnerability** feature on this repository's Security tab. Include the affected version, reproduction steps, and impact. Do not publish exploit details before maintainers have had a chance to prepare a fix.

## Supported version

The latest published release is the supported version. Installers are not code-signed or notarized yet; only download them from this repository's Releases page.
